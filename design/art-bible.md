## 1. 视觉身份定义

> **视觉 DNA: "数字桌游剧场"**
>
> 将桌面角色扮演游戏（TTRPG）的温暖物质感、AI 的精密数字感、以及 2.5D 策略地图的空间深度三者融合。
> 玩家不是在看屏幕——玩家是坐在一张会思考的魔法桌前，AI 主持人从桌面的光影中浮现，引导故事展开。

### 核心视觉锚点

| 锚点 | 描述 |
|------|------|
| **物质感** | 深色木质纹理、羊皮纸色调、微妙的噪点/颗粒感 |
| **数字层** | 微光粒子、柔和的发光边缘、细腻的科技线条动画 |
| **空间深度** | 2.5D 等距地图作为"桌面上的沙盘"，带阴影投射 |
| **焦点引导** | 视觉层次严格：地图(背景) → 对话(核心) → UI(辅助) |

### 情感目标

- **沉浸感**: 玩家感到被"��入"一个由 AI 精心编织的世界
- **可信赖**: AI 主持人的视觉呈现应该是温暖、智慧、有存在感的，而不是冰冷机械的
- **可读性**: 文字是核心玩法内容，任何视觉元素不能干扰文字阅读
- **发现感**: 地图探索时轻微的视觉奖励反馈（微光、粒子）

## 2. 情绪板描述

### 参考方向 A: "暗物质桌面" (核心方向)

**关键词**: 温暖暗色、木质纹理、柔和烛光、手工感

- 深胡桃木色桌面作为底色
- 地图区域如一张铺在桌上的羊皮纸地图
- 对话面板如一本精装书的内页
- 状态栏如桌面边缘的精致金属铭牌
- 整体光源来自"上方"，模拟吊灯光晕

**情绪参考**: Disco Elysium 的 UI 质感、Divinity: Original Sin 2 的界面布局

---

### 参考方向 B: "数字灵光" (AI 存在感层)

**关键词**: 微光粒子、柔和光晕、几何线条、渐隐渐现

- AI 主持人出现时，边缘带柔和的蓝紫光晕
- 地图上可交互位置有细微的脉冲光点
- 对话生成中，文字区域有微弱的流动光效
- 翻页/转场时粒子过渡

**情绪参考**: Control 的 HUD 超自然光效、Monument Valley 的几何美学

---

### 参考方向 C: "2.5D 沙盘剧场"

**关键词**: 等距视角、体素/图块网格、阴影投射、舞台感

- 地图使用 2:1 等距菱形图块
- 每个图块如一个小舞台，角色/物品在其上
- 图块之间有精致的连接线（路径/道路）
- 未探索区域有"战争迷雾"效果的柔和遮罩
- 当前选中图块有聚光灯光晕

**情绪参考**: Into the Breach 的等距网格、Tiny Tina's Wonderlands 的桌游地图表现

---

### 参考方向 D: "字体剧场" (排版驱动)

**关键词**: 衬线标题、等宽数据、层次分明的文本排版

- AI 叙述文本使用衬线字体，模仿故事书排版
- 玩家对话选项使用清晰的无衬线字体
- 数值/状态用等宽数字，精致如仪表盘
- 文本区域留白充裕，行距舒适 (1.6-1.8)

**情绪参考**: Medium 的阅读排版、Kindle 的阅读体验

---

### 参考方向 E: "极简功能层" (UI 框架)

**关键词**: 玻璃质感、微妙边框、图标驱动、最小干扰

- 按钮/面板使用毛玻璃效果 (backdrop-blur)
- 边框为 1px 半透明线条
- 图标优先于文字标签
- hover/active 状态使用柔和的背景色变化

**情绪参考**: macOS Big Sur 的玻璃质感、Figma 的暗色模式界面

### 3.3 配色原则

1. **暗色为主，亮色为辅**: 首发以暗色主题为核心，亮色主题在 Phase 2 实现
2. **暖调偏移**: 所有中性色向暖色偏移 2-3°，避免冷冰冰的数字感
3. **黄金魔法二重奏**: 黄金色代表"玩家/物质世界"，魔法蓝紫色代表"AI/数字领域"
4. **对比度基线**: WCAG AA (正文 4.5:1，大文本 3:1)，详见第 9 节

## 4. 字体系统

### 4.1 字体栈

```css
/* 标题 / AI 叙述 */
--font-narrative: 'Crimson Text', 'Noto Serif SC', 'Source Han Serif SC', Georgia, serif;

/* UI 正文 / 面板 */
--font-ui: 'Inter', 'Noto Sans SC', 'Source Han Sans SC', -apple-system, sans-serif;

/* 等宽 / 数值 */
--font-mono: 'JetBrains Mono', 'Fira Code', 'Noto Sans Mono SC', monospace;

/* 装饰 / 特殊标题 */
--font-display: 'Cinzel', 'Noto Serif SC', serif;
```

### 4.2 排版尺度 (基于 16px 根字号)

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| `text-display` | 2.5rem (40px) | 1.2 | 700 | 游戏主标题/Logo |
| `text-h1` | 1.75rem (28px) | 1.3 | 600 | 面板标题 |
| `text-h2` | 1.375rem (22px) | 1.35 | 600 | 区块标题 |
| `text-h3` | 1.125rem (18px) | 1.4 | 600 | 子标题 |
| `text-body` | 1rem (16px) | 1.6 | 400 | 正文/UI 文本 |
| `text-narrative` | 1.0625rem (17px) | 1.75 | 400 | AI 叙述文本 |
| `text-small` | 0.875rem (14px) | 1.5 | 400 | 次要信息 |
| `text-caption` | 0.75rem (12px) | 1.4 | 500 | 标签/说明 |
| `text-stat` | 1.125rem (18px) | 1.2 | 600 | 数值 (等宽) |

### 4.3 字体加载策略

- `font-display: swap` — 所有 Web 字体使用 swap 策略，防止 FOIT
- 子集化: 中文字体使用 Google Fonts 的动态子集 API
- 后备字体始终声明完整栈
- 预加载关键字体: `<link rel="preload" as="font">` 用于 narrative 和 UI 字体

## 5. 布局系统

### 5.1 桌面端三面板布局 (≥1280px)

```
+-------------------------------------------------------+
|  [Logo]                          [⚙] [📦] [AI头像]   |  ← 顶栏 56px
+----------+----------------------------+----------------+
|          |                            |                |
|  地图     |       对话交互区             |   状态信息栏    |
|  (Map)   |    (Dialogue Center)       |  (Status Bar)  |
|          |                            |                |
| 360px    |       flex: 1              |   300px        |
|          |                            |                |
|          |  ┌─────────────────────┐   |  HP/MP/属性    |
| 2.5D地图  |  │  AI Narrator        │   |  背包预览      |
| 点击移动  |  │  "叙述文本..."       │   |  快捷操作      |
|          |  │                     │   |                |
|          |  │  [选项A] [选项B]     │   |                |
|          |  └─────────────────────┘   |                |
|          |                            |                |
+----------+----------------------------+----------------+

总宽度: 1280px+
地图: 固定 360px (min)
对话区: flex: 1 (min: 480px)
状态栏: 固定 300px (min)
```

### 5.2 响应式断点策略

| 断点 | 宽度 | 布局 |
|------|------|------|
| **Desktop Wide** | ≥ 1440px | 三面板: 380 / flex / 320 |
| **Desktop** | ≥ 1280px | 三面板: 360 / flex / 300 |
| **Desktop Small** | ≥ 1024px | 三面板: 280 / flex / 260 |
| **Tablet Landscape** | ≥ 768px | 两面板: 地图(可折叠) / 对话+状态(上下) |
| **Tablet Portrait** | ≥ 600px | 单面板: 全屏切换模式 |
| **Mobile** | < 600px | 单面板: 全屏切换 + 底部 Tab 导航 |

### 5.3 Mobile 面板切换策略

移动端使用底部 TabBar 在三个视图间切换:
- 🗺️ 地图 / 💬 对话 / 📋 状态
- 对话面板为默认视图
- 地图上有新事件时，地图 Tab 显示脉冲提示点
- 切换使用 200ms ease-out 滑动过渡

### 5.4 CSS 自定义属性布局变量

```css

  --topbar-height: 56px;
  --map-width: 360px;
  --status-width: 300px;
  --panel-gap: 12px;
  --panel-radius: 12px;
  --panel-padding: 20px;
  --narrative-max-width: 680px;  /* 叙述文本最佳阅读宽度 */
}
```

## 6. UI 组件风格

### 6.1 设计语言总则

**"精装书的封面，精密仪器的骨架"**

- 面板内部温暖（纸张/羊皮纸质感），边框精确（细线/微妙阴影）
- 所有交互元素具备清晰的 3 态: default / hover / active
- 圆角统一使用 `8px` (小) / `12px` (面板) / `16px` (模态)
- 所有动画使用 `cubic-bezier(0.4, 0, 0.2, 1)` (Material 标准缓动)

### 6.2 面板 (Panel)

```
┌─────────────────────────────┐
│  Title                    … │  ← 标题栏 (可选)
├─────────────────────────────┤
│                             │
│  Content Area               │  ← bg-panel + 12px radius
│                             │     border: 1px border-subtle
│                             │     box-shadow: 0 4px 24px shadow-panel
│                             │
└─────────────────────────────┘
```

- 背景: `--bg-panel` + backdrop-blur(12px)
- 边框: `1px solid --border-subtle`
- 投影: `0 4px 24px var(--shadow-panel)`
- 内边距: `20px`
- 圆角: `12px`

### 6.3 按钮 (Button)

#### 主要按钮 (Primary)
```
┌──────────────────┐
│   开始冒险        │  ← bg: accent-gold, text: bg-deep
└──────────────────┘     hover: brightness(1.1), active: brightness(0.95)
```

#### 次要按钮 (Secondary)
```
┌──────────────────┐
│   查看详情        │  ← bg: transparent, border: accent-gold
└──────────────────┘     hover: bg: accent-gold at 10% opacity
```

#### 幽灵按钮 (Ghost) — 对话选项
```
   ▶ "是的，我准备好了。"     ← text: text-primary
   ▶ "再等等……"               ← hover: text accent-gold + 左移 4px
                                active: text accent-gold-dim
```

#### 尺寸规格
| 尺寸 | 高度 | 水平内边距 | 字号 |
|------|------|-----------|------|
| Small | 36px | 16px | 14px |
| Medium | 44px | 24px | 16px |
| Large | 48px | 32px | 18px |

### 6.4 地图图块 (Tile)

```
     /\───/\        ← 等距菱形 (2:1 比例)
    /  🏰  \       ← 内容居中
   /    ·   \      ← 选中: accent-gold 边框 + 光晕
   \       /       ← hover: 轻微放大 (scale 1.05)
    \     /        ← 未探索: overlay-fog 遮罩
     \───/
```

- 图块尺寸: 128×64px (菱形外接矩形)
- 图块间距: 4px
- 选中态: `box-shadow: 0 0 20px var(--accent-gold)` + 1px solid border
- 可到达态: `box-shadow: 0 0 10px var(--accent-magic-glow)` + 脉冲动画
- 未探索态: `filter: brightness(0.3)` + overlay

### 6.5 对话框 (Modal)

```
     ╔═══════════════════════╗
     ║  Title            ✕  ║  ← 标题栏
     ╠═══════════════════════╣
     ║                       ║
     ║  Modal Content         ║  ← 内容区
     ║                       ║
     ╠═══════════════════════╣
     ║           [确认] [取消] ║  ← 按钮栏
     ╚═══════════════════════╝

bg: bg-panel-raised, border: 2px border-active
backdrop: overlay-modal + backdrop-blur(4px)
圆角: 16px, 投影: 0 8px 48px shadow-panel
动画: 淡入 + scale(0.95 → 1), 200ms
```

### 6.6 工具提示 (Tooltip)

- 背景: `--bg-panel-raised` + 95% opacity
- 出现延迟: 400ms hover
- 动画: fadeIn 150ms
- 最大宽度: 240px
- 箭头: 6px CSS 三角

### 6.7 滚动条

```css
/* 自定义细滚动条 */
scrollbar-width: thin;
scrollbar-color: var(--border-subtle) transparent;
```

- 不占用布局空间 (overlay scrollbar 优先)
- 地图区域滚动条: 半透明暗色
- 对话区域滚动条: 极细 4px

## 7. 2.5D 地图视觉规范

### 7.1 等距透视定义

```
投影角度: 等距(Isometric) 2:1

         Y轴(北)
          ↗
         /
        /
       +------→ X轴(东)

图块比例: 宽度:高度 = 2:1
菱形顶点: (w/2, 0) → (w, h/2) → (w/2, h) → (0, h/2)
```

### 7.2 图块层级

| 图层 | 尺寸 | 内容 | 渲染方式 |
|------|------|------|---------|
| **地形层** | 128×64px | 草地/石地/水面/沙地 | 预渲染精灵图 |
| **装饰层** | 128×64px | 树木/岩石/建筑轮廓 | 预渲染精灵图 + 阴影 |
| **实体层** | 64×64px | NPC/怪物/物品图标 | 精灵图 + 浮动动画 |
| **粒子层** | 整个图块 | 环境粒子/魔法效果 | CSS 动画/Canvas |
| **UI 叠加层** | 整个图块 | 选中框/路径线/标签 | CSS/SVG |

### 7.3 地图导航与路径

#### 路径线 (Path Lines)
```
●────●  ← 已走过的路: solid, border-subtle, 2px
● ═ ═ ●  ← 可到达路径: dashed, accent-gold, 2px, 呼吸动画
● · · ●  ← 未探索方向: dotted, text-muted, 1px
```

#### 移动预览
- 点击可到达图块时，短暂显示虚线路径 + 脚印图标
- 路径动画: 从起点向终点渐变绘制，300ms

### 7.4 战争迷雾

- 未探索图块: `filter: brightness(0.25) saturate(0.1)` + `overlay-fog`
- 已探索但未在视野内: `filter: brightness(0.6) saturate(0.4)` (灰阶化但不全黑)
- 当前视野: 完整颜色 + 微光边框
- 迷雾边界: 柔和羽化 (使用 CSS mask-image 或 box-shadow spread)

### 7.5 地图主题变体

| 环境 | 地形色调 | 特色装饰 |
|------|---------|---------|
| 森林 | `#3A5A2E` 基底, `#5C8A42` 高光 | 树冠阴影, 斑驳光点 |
| 洞穴 | `#2A2420` 基底, `#4A3A30` 高光 | 钟乳石剪影, 荧光粒子 |
| 城镇 | `#8B7D6B` 基底, `#C4B5A0` 高光 | 建筑屋顶, 灯火窗口 |
| 水域 | `#2E4A6B` 基底, `#4A7A9B` 高光 | 波纹动画, 倒影 |

### 7.6 地图缩放

- 默认缩放: 1x (128px 图块)
- 缩放范围: 0.5x ~ 2x
- 缩放控件: 地图角落 +/- 按钮 + 鼠标滚轮
- 缩放 > 1.5x: 显示图块细节标签（地名/类型）

## 8. AI 主持人视觉呈现

### 8.1 AI Narrator 层级体系

```
Level 0 — 隐形
  AI 无视觉呈现，仅文本输出

Level 1 — 对话标识
  文本前缀 "🧙 DM: " + 文字颜色 accent-magic
  
Level 2 — 头像模式 (默认)
  圆形头像 + 名称标签 + 叙述气泡
  ┌─────────────────────────────┐
  │  ┌────┐                     │
```

## 9. 可访问性初步考虑

### 9.1 可访问性目标分级

**目标: Standard 级**（详见 `design/accessibility-requirements.md`）

- WCAG 2.1 AA 合规
- 键盘全导航
- 屏幕阅读器友好
- 基础色盲友好

### 9.2 对比度合规

| 元素 | 前景 | 背景 | 对比度 | WCAG 等级 |
|------|------|------|--------|-----------|
| 正文 | `#E8E0D5` | `#1E1B18` | 10.2:1 | **AAA** ✓ |
| 叙述文本 | `#F0E6D3` | `#1E1B18` | 10.9:1 | **AAA** ✓ |
| 次要文本 | `#A09888` | `#1E1B18` | 5.3:1 | **AA** ✓ |
| 静音文本 | `#6B6258` | `#1E1B18` | 3.2:1 | - (装饰性) |
| 黄金按钮文字 | `#0D0D12` | `#C9A94E` | 8.7:1 | **AAA** ✓ |
| 魔法按钮文字 | `#FFFFFF` | `#7B6FDF` | 4.9:1 | **AA** ✓ |

### 9.3 色盲友好策略

1. **不依赖颜色传达关键信息**: 
   - HP 条: 颜色 + 数字 + 条形长度三通道
   - 地图可到达/不可到达: 颜色 + 图标(✓/✗) + 光标样式
   - AI 状态: 颜色 + 形状 + 动画模式三通道

2. **红绿色盲安全色板** (参考 ColorBrewer):
   - 危险/警告: 使用 `#C85554` (偏橙红) 而非纯红
   - 成功/恢复: 使用 `#5A9E6F` (偏蓝绿) 而非纯绿
   - 信息: 使用 `#5B8CBE` (偏青蓝)

3. **高对比度模式** (计划 Phase 2):
   - 切换开关: 增加所有边框宽度至 2px+
   - 移除 backdrop-blur 效果
   - 白色 halo 加在聚焦元素上

### 9.4 字体缩放策略

- 使用 `rem` 单位全局，根字号可缩放
- 支持浏览器默认字体缩放 (Ctrl+/Ctrl-)
- 最小字号不低于 12px (0.75rem)
- 行高固定为比例值（不随字号缩放断裂）

### 9.5 减少动效 (prefers-reduced-motion)

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

减少动效时:
- AI 粒子动画 → 静态光晕
- 地图脉冲 → 静态高亮边框
- 路径动画 → 即时显示
- 面板过渡 → 即时切换

### 9.6 键盘导航

- Tab 键序: 地图 → 对话面板(选项) → 状态栏 → 顶栏
- Enter/Space: 确认当前焦点元素
- 方向键: 地图上移动选择图块
- Escape: 关闭模态/取消操作
- 可见焦点指示器: `outline: 2px solid accent-gold` + `outline-offset: 2px`

### 9.7 屏幕阅读器

- 地图图块: `aria-label="[地形类型]: [位置名称], [状态]"` 例: "森林: 古老橡树, 可探索"
- AI 叙述: 使用 `aria-live="polite"` 区域，AI 文字实时播报
- 状态变化: 使用 `aria-live="assertive"` 播报 HP/MP 变化
- 图标必须有 `aria-label` 或隐藏 (`aria-hidden="true"` 仅装饰性图标)

- 字体子集: 每个 < 100KB
