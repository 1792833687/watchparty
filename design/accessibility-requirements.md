## 1. 三档可访问性分级定义

### 1.1 分级总览

| 级别 | 名称 | 适用阶段 | WCAG 目标 | 描述 |
|------|------|---------|-----------|------|
| **L1 Basic** | 基础可访问 | MVP Must Have | WCAG 2.1 **A** | 最低合规线——确保游戏基本可用，不排斥任何用户群体 |
| **L2 Standard** | 标准可访问 | Should Have (目标级别) | WCAG 2.1 **AA** | 提供与主流产品一致的可访问体验——本项目的承诺级别 |
| **L3 Comprehensive** | 全面可访问 | Could Have | WCAG 2.1 **AAA** (部分) | 追求最大包容性——满足特定用户群体的深度需求 |

### 1.2 适用范围说明

本项目为 **桌面端优先的 Web 应用**（Next.js + React），兼顾平板设备。以下分级以桌面端为主要标定场景，平板端在触控目标维度单独标注。

### 1.3 各级别核心要求摘要

#### L1 Basic — 基础可访问 (WCAG 2.1 A)

- 正文与小文本对比度 ≥ 3:1（大文本）、≥ 4.5:1 优先
- 所有交互元素可通过键盘访问（不一定是完整键盘流）
- 图片 / 图标有替代文本 (`alt` / `aria-label`)
- 不使用仅依赖颜色的信息传达
- 无键盘陷阱
- 表单输入有标签
- 错误由文本提示（不纯依赖颜色或图标）

#### L2 Standard — 标准可访问 (WCAG 2.1 AA) ★ 本项目目标

- 正文对比度 ≥ 4.5:1，大文本 ≥ 3:1
- **完整键盘导航**：Tab 序合理、焦点指示器可见、快捷键不冲突
- **屏幕阅读器优化**：语义 HTML、`aria-live` 动态区域、`role` 明确
- **色盲友好三通道策略**：颜色 + 形状 + 动画模式同时传达
- **字体缩放**：`rem` 全局使用、200% 缩放不破坏布局
- **动效控制**：尊重 `prefers-reduced-motion`
- **触控目标 ≥ 44×44 CSS px**（平板端）
- 错误恢复友好：对话输入错误、网络断开、LLM 超时等异常场景有清晰指引

#### L3 Comprehensive — 全面可访问 (WCAG 2.1 AAA，部分)

- 正文对比度 ≥ 7:1，大文本 ≥ 4.5:1
- 高对比度模式切换开关
- 屏幕阅读器专用导航快捷键（如跳转到地图 / 对话 / 状态栏）
- 完整键盘替代所有鼠标操作（包括地图拖拽、缩放等）
- 字幕 / 文本替代所有纯音频信息
- 自定义字体缩放（独立于浏览器缩放）
- 所有动画可完全关闭（不仅仅是 reduced）
- 会话暂停 / 恢复保护（用户离开后自动保存状态）

## 2. 特性矩阵

### 2.1 视觉对比度

| 特性 | L1 Basic | L2 Standard (目标) | L3 Comprehensive |
|------|---------|-------------------|-----------------|
| **正文对比度** | ≥ 3:1 (大文本) | **≥ 4.5:1** | **≥ 7:1** |
| **次要文本对比度** | 不限 | **≥ 3:1** (≥ 18px/粗体 14pt) | **≥ 4.5:1** |
| **UI 组件对比度** | 视觉可分辨 | **≥ 3:1** (边框/图标与相邻色) | **≥ 4.5:1** |
| **焦点指示器对比度** | 可见即可 | **≥ 3:1** vs 背景 | **≥ 4.5:1** |
| **高对比度模式** | — | — | 切换开关：2px+ 边框、移除 blur、白 halo |
| **亮色主题** | — | Phase 2 实现 | 与暗色主题同等对比度 |

**当前暗色主题合规状态**（引用 `art-bible.md` §9.2）:

| 元素 | 对比度 | L2 达标 |
|------|--------|---------|
| 正文 `#E8E0D5` / `#1E1B18` | 10.2:1 | ✅ AAA |
| 叙述文本 `#F0E6D3` / `#1E1B18` | 10.9:1 | ✅ AAA |
| 次要文本 `#A09888` / `#1E1B18` | 5.3:1 | ✅ AA |
| 静音文本 `#6B6258` / `#1E1B18` | 3.2:1 | ⚠️ 仅装饰性 |
| 黄金按钮 `#0D0D12` / `#C9A94E` | 8.7:1 | ✅ AAA |
| 魔法按钮 `#FFFFFF` / `#7B6FDF` | 4.9:1 | ✅ AA |

**结论**: 暗色主题已全面达到 L2 Standard 对比度要求。唯一待验证项：`--bg-input`（`#2A2522`）上的 `--text-muted`（`#6B6258`）用于占位文本时是否需要提升至 ≥ 4.5:1。

**对话系统键盘流**（定义自 `dialogue-system.md`）:

```
Tab: 输入框 → 建议动作卡片 (逐个) → 发送按钮
方向键 ↑↓: 在建议动作卡片间快速切换
Enter: 执行选中的建议动作 / 发送输入
Escape: 关闭抉择面板
```

```
Tab: 地图面板获取焦点
方向键: 按等距网格移动选择框 (焦点图块)
Enter: 点击当前焦点图块 (触发移动)
Escape: 取消选择 / 退出缩放
+/-: 缩放地图
```

**关键 aria-live 区域布局**:

```
┌──────────────────────────────────────────────────────┐
│ aria-live="polite" (AI 叙述区域)                     │
│ - AI GM 的对话文本持续更新                            │
│ - 优先级低：不打断当前阅读                            │
├──────────────────────────────────────────────────────┤
│ aria-live="assertive" (状态变化区域)                  │
│ - HP/MP 变化、物品获取 / 失去、位置切换                │
│ - 优先级高：立即播报                                  │
├──────────────────────────────────────────────────────┤
│ role="status" (AI 状态指示器)                         │
│ - "AI 思考中…" / "AI 正在叙述" / "等待你的回应"       │
└──────────────────────────────────────────────────────┘
```

**地图图块 aria-label 模板**:

```
aria-label = "[地形类型]: [图块名称], [交互状态]"

示例:
- "森林: 古老橡树, 可探索"
- "城镇: 铁匠铺, 商人巴尔在铁砧旁"
- "洞穴: 水晶矿脉, 已探索"
- "黑暗森林: 未知区域, 未探索"
```

### 2.6 动效控制

| 特性 | L1 Basic | L2 Standard (目标) | L3 Comprehensive |
|------|---------|-------------------|-----------------|
| **prefers-reduced-motion** | — | **完全尊重**：动画降为瞬时或大幅减弱 | 动画可完全关闭 |
| **AI 粒子动画** | — | → 静态光晕 | 所有粒子关闭 |
| **地图脉冲** | — | → 静态高亮边框 | 无动画指示器 |
| **路径动画** | — | → 即时显示完整路径 | 同 L2 |
| **面板过渡** | — | → 即时切换（无滑动/淡入） | 同 L2 |
| **选项卡片交错滑入** | — | → 同时显示（无 stagger） | 同 L2 |
| **头像脉动** | — | → 静态头像 | 同 L2 |
| **流式输出动画** | — | → 直接渲染完整文本（非打字机模式默认关闭） | 同 L2 |
| **动效总开关** | — | — | 独立于系统设置的全局开关 |

**实现方式**（引用 `art-bible.md` §9.5）:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

**替代方案映射表**:

| 动画元素 | 正常模式 | Reduced Motion |
|----------|---------|---------------|
| AI 粒子环绕 | 12-20 粒子椭圆轨道 | 静态光晕 (box-shadow) |
| 地图可到达脉冲 | 脉冲动画 2s | 静态高亮边框 (accent-magic-glow) |
| 路径绘制 (dash) | 渐绘 300ms | 即时显示完整虚线 |
| 面板过渡 | 淡入 + scale 200ms | 即时切换 |
| 建议卡片滑入 | stagger 50ms × 5 | 同时显示 |
| AI 头像脉动 | 脉动 2s 周期 | 静态头像 |
| 地图图块 hover | scale 1.05 150ms | 亮度变化 (无缩放) |
| 粒子背景 (对话面板) | 流动光效 | 静态渐变 |

**按钮尺寸触控合规检查**（引用 `art-bible.md` §6.3）:

| 按钮尺寸 | 高度 | 水平内边距 | 触控达标 | 修复建议 |
|---------|------|-----------|---------|---------|
| Small | 32px | 16px | ❌ 32px < 44px | **提升至 36px 并确保 min-width 44px，或内部填充区域 ≥ 44px** |

### 2.8 错误恢复

| 特性 | L1 Basic | L2 Standard (目标) | L3 Comprehensive |
|------|---------|-------------------|-----------------|
| **对话输入错误** | — | 空输入 → AI GM 主动叙述；过长输入 → 截断提示 | 智能纠错建议 |
| **LLM 超时 (>30s)** | — | 超时提示 + 重试按钮 + 模型切换引导 | 自动回退到备用模型 |
| **API 不可达** | — | "AI GM 暂时失联" + 重试 (1s/3s/9s) + 离线阅读缓存 | 自动切换至本地模型 |

| **流式连接中断** | — | Fallback 非流式补全 + 显示已收到部分 | 同 L2 |
| **网络断开** | — | 检测 + 提示 + 本地缓存最后状态 | 离线模式（纯本地） |
| **存档错误** | — | 错误提示 + 重试 + 导出备份 | 自动备份 |
| **地图数据损坏** | — | "地图数据异常" + 重建选项 | 从云端恢复 |
| **Token 超限** | — | 自动压缩 + 提示"较早对话可能被遗忘" | 同 L2 |
| **敏感内容** | — | 过滤 + `[内容已过滤]` + GM 引导回到安全叙事 | 用户可配置过滤级别 |
| **表单验证错误** | 基础提示 | 错误字段高亮 + 文字说明 + 修复建议 | 同 L2 |
| **多 Tab 冲突** | — | 检测 → "已在另一个标签页打开" → 只读模式 | 跨 Tab 状态同步 |

**关键错误场景的 UX 文案规范**:
