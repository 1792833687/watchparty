分层结构（z 序）：天空多段渐变 → 光晕（月/落日/火光/暗能量）→ 远层山脊剪影 → 近层剪影（松树/塔楼/断柱/石笋/钟乳石/草丛）→ 粒子（飘雪/火星/萤火/星点/雾气/岩尘，CSS 动画）→ 底部雾带。
技术要点：单 SVG viewBox 0 0 400 120 + preserveAspectRatio 实现全尺寸响应式；粒子坐标固定种子伪随机（SSR/客户端 hydration 一致，不闪烁）；粒子动画走 CSS keyframes，可被系统「减少动效」全局灭活；色板全部来自 tokens.ts 单一事实源。
