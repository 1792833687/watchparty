# 凛冬要塞：暗影纪元 — 结构化设定摘要

**文档版本**：v3.0（灵魂印记版）  
**游戏类型**：中世纪魔幻文字叙事·领地经营·冒险策略  
**AI 角色**：吟游诗人（旁白+仲裁者）  
**核心主题**：光明与黑暗的内心斗争、力量与代价的永恆博弈、选择与后果的不可逆转

---

## 一、世界观

- **核心地点**：凛冬要塞——阴影山脉隘口的古老黑花岗岩要塞，建于第三纪元初。
- **世界格局**：光明势力（刚铎、洛汗、孤山矮人、林地精灵、瑞文戴尔精灵、北方游侠）对抗黑暗君主魔苟斯的黑暗势力（戒灵、半兽人、食人妖、炎魔、龙等）。
- **纪元划分**：四纪元推进——孤守要塞 → 联合诸族 → 光暗交锋 → 命运终局。
- **区域结构**：以要塞为中心，向外辐射六个区域：凛冬谷（安全）、暮色森林（警戒）、阴影山脉（危险）、荒芜平原（危险）、黑曜石荒原（致命）、龙脊冰峰（致命）。

## 三、属性系统

### 3.1 六维属性

| 属性 | 缩写 | 影响范围 |
|------|------|----------|
| 力量 | STR | 近战伤害、负重、破门、威慑 |
| 敏捷 | DEX | 远程伤害、闪避、潜行、陷阱、先攻 |
| 体质 | CON | 生命值上限、抗性、疲劳恢复、抵抗堕落 |
| 智力 | INT | 奥术法术强度、古代语、炼金术、鉴定 |
| 感知 | WIS | 神圣法术强度、察觉、追踪、抵抗诱惑 |
| 魅力 | CHA | 外交、交易、鼓舞士气、同伴忠诚 |

- 范围：1-20（凡人极限）
- 检定公式：D20 + 属性调整值（(属性-10)/2 向下取整）+ 熟练加值

### 3.2 生命值与死亡豁免

- **生命值上限** = 10 + 体质调整值×等级 + 种族加成
- **种族加成**：人类 +2/级，矮人 +3/级，精灵 +1/级，半身人 +1/级
- **死亡豁免**：D20 ≥10 为成功（3 次成功稳定），<10 为失败（3 次失败陨落），投出 20 恢复 25%，投出 1 计 2 次失败
- **永久伤痕**：每次死亡豁免后获得（如脸上疤→魅力-1 但战士交涉优势）

## 五、堕落值与暗影低语系统（核心创新）

### 5.1 堕落值（0–100）

**增加途径**：使用死灵法术（+2~5）、接触黑暗圣物（+5~15）、滥杀（+3~8）、与黑暗生物交易（+10~20）、主动暗影低语（+3~20）、「命运的初次触碰」（+5，不可回避）

**减少途径**：圣地祈祷（-5~10/周限一次）、完成正义事迹、精灵女王祝福（-15~25，仅一次）、摧毁黑暗圣物、同伴劝说（忠诚度≥80 仅一次）

### 5.2 堕落阶段

| 阶段 | 范围 | 效果 |
|------|------|------|
| 纯净 | 0-20 | 神圣法术+10%，恐惧免疫 |
| 微染 | 21-40 | 噩梦，感知检定-1 |
| 侵蚀 | 41-60 | 魅力-2，解锁初级暗影低语 |
| 暗影 | 61-80 | 黑暗法术+20%，神圣法术禁用，解锁高级暗影低语 |
| 堕落 | 81-99 | 获得强力能力，行为可能失控 |
| 深渊 | 100 | 触发"陨落"结局 |

### 5.3 暗影低语系统

- **被动初次触发**：堕落值 20-30 时必触发「游离之魂」事件——拯救重伤女孩艾拉（无标签无代价提示）
- **主动触发**（堕落值≥41）：战斗、审讯、围城、同伴濒死等场景提供暗影低语选项，100% 成功但每次增堕落值

## 十二、特殊规则

- **双维关系系统**：好感度（0-100）+ 忠诚度（0-100）
- **忠诚度审判**：关键剧情点强制触发同伴信念冲突，有第三方介入机制
- **代价性成功**：完美胜利需暗影力量；光荣成功伴随牺牲；妥协成功以道德/同伴关系为代价
- **灵魂印记**：关键选择留下不可消除的叙事印记（如艾拉的命运）
- **传承系统**：失败后新局继承编年史传说 + 遗物装备 + 部分世界状态，难度不可降级
- **通关书信**：根据结局生成《致领主书》来自敌人/同伴/被拯救之人
- **难度设定**：游侠（叙事）/ 守护者（均衡）/ 史诗（极限）/ 自定义模式
