## 3. P1 — 重要

### P1-1：堕落值六阶段 UI

| 项目 | 详情 |
|------|------|
| **目标** | 在 CharacterPanel 增加堕落值进度条和六阶段（微光→裂痕→侵蚀→深渊→虚空→湮灭）指示器 |
| **当前问题** | currentCorruption 状态存在但在 CharacterPanel 中无展示，玩家无法感知阶段变化 |
| **涉及文件** | CharacterPanel.tsx（新增堕落值组件段）、PanelContainer.tsx（透传 corruption）、page.tsx（透传 currentCorruption） |
| **实现方案** | ① 六阶段阈值：微光 0-15 / 裂痕 16-30 / 侵蚀 31-50 / 深渊 51-75 / 虚空 76-99 / 湮灭 100；② UI：横向进度条 + 阶段标签，每阶段有独立配色提示；③ 阶段临界值触发系统提示词注入 |
| **工作量** | 2 人日 |
| **前置依赖** | 无 |

### P1-2：阵营声望 5 级交互

| 项目 | 详情 |
|------|------|
| **目标** | 6 个阵营增加 5 级声望阶梯（中立 0→冷淡 1→友善 2→尊敬 3→崇拜 4），支持 AI GM 根据声望调整对话 |
| **当前问题** | factions 仅作静态列表展示，无数值无交互 |
| **涉及文件** | page.tsx（gameState 新增 factionReputations 字段）、CharacterPanel.tsx（声望可视化）、PanelContainer.tsx（透传）、types.ts（新增 FactionReputation 类型） |
| **实现方案** | ① gameState 新增 `factionReputations: Record<string, number>`，初始值从 preset.factions 的 attitude 映射；② CharacterPanel 中每个阵营显示 5 段阶梯；③ 系统提示词注入阵营声望上下文 |
| **工作量** | 2 人日 |
| **前置依赖** | 无 |

### P1-3：暗影低语 & 游离之魂

| 项目 | 详情 |
|------|------|
| **目标** | 实现堕落值首次 15+ 时的「游离之魂」被动触发，以及 30+ 后的主动「暗影低语」选项 |
| **当前问题** | 文档描述的两种机制均未实现 |
| **涉及文件** | page.tsx（handleSend 中新增 corruption tick）、DialogueOptions（新增"暗影低语"特殊选项） |
| **实现方案** | ① 堕落值首次 ≥15 时，AI 回复自动追加游离之魂旁白；② 堕落值 ≥30 时，对话选项列表追加"聆听暗影低语"选项；③ 低语使用后效果（优势检定但增加堕落值 3-8） |
| **工作量** | 2.5 人日 |
| **前置依赖** | P1-1（六阶段 UI 先行，否则触发无反馈） |

### P1-4：D20 检定可视化

| 项目 | 详情 |
|------|------|
| **目标** | 在 AI 对话中嵌入 D20 检定指令块，前端解析渲染掷骰动画+结果 |
| **当前问题** | 检定由 AI GM 在叙事中隐式处理，无掷骰反馈 |
| **涉及文件** | page.tsx（新增 CHECK 块解析器）、新增 CheckDiceOverlay 组件 |
| **实现方案** | ① 系统提示要求 AI 在需要检定时输出 `[CHECK:attr:STR:DC:15]` 格式；② 前端解析后渲染掷骰动画（D20 翻转→显示结果+修正→成功/失败动画）；③ 属性修正值=Math.floor((attr-10)/2) |
| **工作量** | 3 人日 |
| **前置依赖** | 无 |
