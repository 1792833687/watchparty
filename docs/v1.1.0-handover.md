## 二、数据流架构（v1.1.0）

### 完整链路

```
GAME_SETTING_TEMPLATES (settings-loader.ts)
  └─ 5 个预设各含 themeData: { attributes, skillCategories, startingItems, mapRegions, forbiddenTerms }
       │
BUILD_PRESET(pid) (game/new/page.tsx)
  └─ 将 themeData 注入返回的 GameSetting 对象
       │
fullSetting = rawSetting || localSetting || importedSetting
       │
deriveAttrMeta(fullSetting.themeData) → { attrNames, attrLabels, attrDescs }
       │
       ├─→ CharacterCreation: attrLabels / attrDescs / availableClasses
       ├─→ PanelContainer: themeCategories / attrLabels / attrDescs
       │     ├─→ SkillsPanel: themeCategories → buildThemeConfig()
       │     ├─→ CharacterPanel: attrLabels / attrDescs
       │     ├─→ InventoryPanel: gameState.items (初始化自 themeData.startingItems)
       │     └─→ MapPanel: gameState.regions (初始化自 themeData.mapRegions)
       │
       └─→ system prompt: forbiddenTerms 注入 AI GM 提示词
```

### 关键函数

| 函数 | 位置 | 作用 |
|------|------|------|
| `deriveAttrMeta(themeData)` | `page.tsx` | 从 `themeData.attributes` 提取 `attrNames` / `attrLabels` / `attrDescs` |
| `buildThemeConfig(categories)` | `SkillsPanel.tsx` | 将 `themeData.skillCategories` 转为 UI 技能树配置 |
| `getDefaultGameState(name, themeData)` | `page.tsx` | 用 `themeData.startingItems` / `mapRegions` 生成初始游戏状态 |

## 六、已知问题与注意事项

1. **InventoryPanel / MapPanel 兜底值**：当 `gameState.items` / `gameState.regions` 为空时，仍使用 `DEFAULT_ITEMS` / `DEFAULT_REGIONS` 通用兜底（奇幻主题），不会根据当前世界观切换兜底。实际游戏中 `getDefaultGameState` 已从 `themeData` 初始化，正常流程不会触发此兜底。
2. **settings-loader.ts 的 GAME_SETTING_TEMPLATES** 与 **BUILD_PRESET** 各自独立维护主题数据，修改预设时需两边同步。
3. **属性名使用英文 id**（如 `insight`），显示标签通过 `attrLabels` 映射为中文（如"洞察力"），数据流中始终传递 id。
4. **不要导入 `openrouter/client`** — 会导致 settings 页崩溃。
5. **不要使用 Tailwind** — 所有组件使用纯内联 style。
6. **版本号**：`package.json` 和 `src/app/page.tsx` footer 均为 `v1.1.0`。
