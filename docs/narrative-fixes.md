### #2 ✅ P0-2 · 预兆梦系统（主角弧光）

**评审**：主角身份空洞——守夜人是"任命"不是"选择"，没有"为什么在乎要塞"的私人理由。

**落地**：
- GAMESTATE 新增 `propheticDream` 字段（count/last/motif），随存档走（吸取 R7 教训）
- system prompt 新增【预兆梦协议】：主角每夜梦见"要塞陷落/火中女孩/背对黑影"，内容随堕落值严格分档：
  0-20 守护之人（情感锚点）→ 21-40 面目模糊（恐惧）→ 41-60 梦里自己是放火者（自厌）→ 61+ 黑影转身露脸（镜像）
- 首次过夜必触发，每 3-4 次休整至少一次；艾拉事件后梦中女孩的脸与艾拉重合（长程因果）
- 前端：梦境残响以 `🌙 梦境残响` 系统消息播报

### #3 ✅ P1-3 · 镜像反派「鸦羽」

**评审**：反派无人格——魔苟斯是背景板，缺一个"走完主角可能走的路"的镜像角色。

**落地**：
- system prompt 新增【镜像反派：鸦羽】：二十年前前任守夜人，为守要塞使用暗影低语逐步堕落叛投，是"主角如果一直用暗影之力会变成的样子"；终局战 = 打"可能的自己"
- 暗影低语选项 hint 加鸦羽呼应：*"（记忆深处：二十年前的守夜人鸦羽，也曾站在这里聆听……）"*
- 虚空守望者真结局 letter 叙事升级：走完鸦羽的路但没有坠落——**打破镜像**
- GAMESTATE 新增 `crowFeather`（echoes/revealed/confront），随存档走

### #4 ✅ P1-5 · 凛冬议会（首个场景级分支）

**评审**：分支在"数值"不在"场景"——选择只改数字，不改"接下来发生什么戏"。

**落地**：
- system prompt 新增【凛冬议会】协议：主线「王国的裂痕」完成后触发战争议会，四派立场分裂（塔林=闭城自守 / 罗兰=主动出击 / 艾琳=向幽林精灵求援 / 格朗=与黑暗谈判），主角必须支持一方（代价题）
- GAMESTATE 新增 `councilDecision`（fortify|strike|aid|negotiate），随存档走
- **前端忠诚结算**：支持方领袖 loyalty +5，被否决三派领袖 -10（setRelationships + 关系链亲和同步）
- 决策后注入 AI 上下文：围城战按对应战术形态演绎（守城/出城/援军入场）

### #5 ✅ P1-6(节拍) · 叙事节拍表注入 prompt

**落地**：system prompt 新增【叙事节拍表】：四纪元强制节拍（纪一：预兆梦/艾拉事件/围城前兆/首位同伴；纪二：王国裂痕/凛冬议会/结盟确认；纪三：鸦羽现身/黑暗圣物抉择/围城战；纪四：终焉之战/结局裁决）——**AI 只在节拍之间自由发挥，节拍不可跳过**。
- 前端注入当前天数 + 进度提示：`（叙事节拍通知）当前是第 X 天…`（dayCount≥15 且艾拉未救时主动引导；鸦羽 echoes>0 且 dayCount≥30 时提示现身）
