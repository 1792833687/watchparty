### 4.2 错误处理缺失

| 场景 | 当前处理 | 风险 |
|------|----------|------|
| LLM 响应无 GAMESTATE 块 | `parseGameState` 返回 null，静默跳过 | 🔴 高：AI 产出状态更新丢失 |
| SSE 流失败回退 | `onError` 回调中自动 fallback 到非流式 | 🟡 中：fallback 也可能失败 |
| API Key 缺失 | `throw new Error` 并显示系统错误消息 | 🟢 低：用户可见提示 |
| localStorage 读写 | 所有操作包裹 try/catch | ✅ 良好 |

### 4.3 localStorage 异常处理

✅ **处理良好**。所有 localStorage 操作均使用 try/catch 包裹：
- `getCustomApiConfig()` 捕获 JSON 解析异常返回 null
- 存档保存/加载/删除均有 catch 块 + console.error
- API Key 读取使用 secureGet → fallback 到明文 localStorage

### 4.4 LLM 响应解析鲁棒性

| 解析器 | 鲁棒性 | 问题 |
|--------|--------|------|
| `parseGameState` | 🟡 中等 | 使用 Zod 校验增加了安全性（`safeParseGameState`），但只匹配第一个 JSON 对象；无重试机制 |
| `parseDialogueOptions` | 🟡 中等 | 使用 Zod 检验，但只匹配第一个 JSON 数组 |
| `stripGameStateBlock` | 🟢 良好 | 简单字符串切割，容错好 |
